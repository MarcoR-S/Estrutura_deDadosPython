# 🐍 Exercícios de Python: Estruturas de Dados

Este repositório contém a resolução de uma trilha de exercícios focada em fundamentos de Python, abrangendo desde manipulação básica de listas até estruturas de dados combinadas (listas com dicionários).

## 🚀 Tecnologias Utilizadas
* **Python 3.x**
* **VS Code** (Ambiente de Desenvolvimento)

---

## 📚 Conteúdo dos Exercícios

O projeto está dividido por níveis de complexidade, conforme o guia de estudos:

### 🟢 Nível 1 — Básico
1.  **Lista de Compras:** Criação e exibição de itens.
2.  **Adicionando Itens:** Uso do método `.append()` para entrada de dados do usuário.
3.  **Removendo Itens:** Manipulação de listas com `.pop()`.

### 🟡 Nível 2 — Manipulação de Listas
4.  **Inserindo no Meio:** Uso do `.insert()` para manter a ordem lógica.
5.  **Soma de Valores:** Cálculo de totais utilizando laços de repetição (`for`).
6.  **Validação de Lista:** Função para verificar tipos de dados e tratar erros.

### 🟠 Nível 3 — Tuplas
7.  **Dados Fixos:** Armazenamento de informações imutáveis de produtos.
8.  **Sistema de Imposto:** Lógica de decisão baseada em faixas salariais e alíquotas.

### 🔵 Nível 4 — Dicionários
9.  **Cadastro Simples:** Estruturação de dados com Chave:Valor.
10. **Preenchimento Dinâmico:** Captura de dados do usuário para alimentar dicionários.

### 🔴 Nível 5 — Estruturas Combinadas
11. **Lista de Alunos:** Gerenciamento de múltiplos dicionários dentro de uma lista.
12. **Sistema de Contatos (Projeto Final):** Mini CRUD (Create, Read) com menu interativo para gerenciar contatos.
